# For My Love — Romantic Website

A responsive pink-themed romantic website with a clickable heart, a step-by-step love story, relatable photos on each screen, and **Prithibir Joto Sukh** looping in the background.

## Run it
1. Extract `for_my_love_website.zip`.
2. Open `index.html` in a modern browser.
3. Click the heart to begin the story and start the song.
4. Use the music button at the bottom to pause or resume.

## Customize
- Edit headings, messages, and photo URLs in `script.js` inside the `story` array.
- Change colors, fonts, spacing, and animations in `style.css`.
- The song is embedded from YouTube and the photos load from Unsplash, so an internet connection is required. Browsers generally block audio autoplay until the visitor clicks; the song starts on the first heart click and is set to loop.
- Browser interactions use JavaScript (not Java).
